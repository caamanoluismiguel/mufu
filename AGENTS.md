# Instrucciones para agentes

Las reglas de este repositorio están en **`.claude/CLAUDE.md`**: qué archivos se generan
y no deben editarse a mano, el ciclo de build y tests obligatorio antes de cada commit,
y las trampas que rompen el CI.

Lo más importante, si no vas a leer nada más: **aquí trabaja más de un agente.** Haz
`git fetch` antes de editar y comprueba que no vas por detrás de `origin/main`.
